## Compito 1 — il tetto diventa funzione della taglia

**Obiettivo.** `tettoFotogrammi(taglia)` in `strumenti/_q-invarianti.js`,
al posto della costante unica `TETTO_FOTOGRAMMI = 18000`.

**Le misure (fatte prima di scrivere la funzione).**
1. Verifica del falso «difetto freekick»: `fuori/_misura-seme-20260924.js`
   — seme 20260924, taglia 11, ordine giusto, tetto locale 40000. Risultato

2. Pre-rigori per taglia: `fuori/_misura-preRigori.js --taglia T --n N

   `G.rigori` diventa vero (si apre la serie) o `t.state==='end'`

3. Oltranza per taglia (verifica, non ridiscussione): `fuori/
   _misura-oltranza.js --taglia T --serie N` — forza `t.rigori()`
   ripetuto, misura il MASSIMO fotogrammi per un solo tiro. Girare a

   328) e a taglia 11 (la taglia piu' lontana da 5). Se il massimo a 11
   fosse sistematicamente piu' alto di quello storico a 5, la componente
   oltranza NON e' taglia-indipendente e il piano si ferma per rivedere
   la spec.

**La funzione.**
```
const TETTI_PER_TAGLIA = { 5: 18000, 7: <misurato>, 11: <misurato> };
function tettoFotogrammi(taglia) {
  const t = [5,7,11].includes(+taglia) ? +taglia : 5;
  return TETTI_PER_TAGLIA[t];
}
const TETTO_FOTOGRAMMI = tettoFotogrammi(5);  // backcompat: stesso valore di sempre
```
Ogni numero in `TETTI_PER_TAGLIA` porta un commento con: campione (N
partite, semeBase, data), massimo osservato, margine applicato e perche',
componente oltranza (costante, con la prova di taglia-indipendenza),
somma, arrotondamento.

**Il test-condanna, PRIMA della funzione.** `strumenti/_t-metro-taglia.js`:
legge il seme 20260924 a taglia 11 (stessa sonda della misura 1), confronta
la durata osservata sia contro il tetto FLAT storico (18000: sempre falso
positivo, per costruzione, indipendentemente dalla cura) sia contro
`tettoFotogrammi(11)` (importato da `_q-invarianti.js`: prima che la
funzione esista, l'import e' `undefined` e il test uscira' 2/rosso per
struttura — dopo la cura, verde). Eseguito PRIMA di scrivere la funzione:
deve uscire rosso/banco. Eseguito DOPO: verde.

**Aggiornare i consumatori** (non ricreare copie locali, voce #127/#121
